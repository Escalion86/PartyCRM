# VK Group Integration Guide

Интеграция VK принимает входящие сообщения из одной или нескольких групп VK,
создает заявки в PartyCRM и сохраняет переписку по каждому диалогу.

Настройка выполняется на уровне компании в
`Настройки компании -> Интеграции -> VK`.

## Что нужно со стороны VK

1. Группа VK, где включены сообщения сообщества.
2. Токен сообщества с правами на сообщения.
3. Callback API для группы.
4. Строка подтверждения сервера Callback API.
5. Secret key Callback API.

## Подключение

1. В PartyCRM откройте `Настройки компании -> Интеграции -> VK`.
2. Нажмите `Добавить группу VK`.
3. Укажите `Название интеграции`: это имя будет сохраняться как источник
   заявки, например `VK Дни рождения` или `VK Корпоративы`.
4. Укажите `Group ID`.
5. Укажите токен сообщества VK.
6. Укажите строку подтверждения Callback API.
7. Нажмите `Подключить` для этой группы.
8. Скопируйте webhook URL и `Secret key` именно из блока этой группы.
9. В управлении группой VK откройте `Работа с API -> Callback API`.
10. Добавьте сервер, вставьте webhook, secret key и подтвердите сервер.
11. В типах событий включите входящие сообщения.

Для второй и последующих групп повторите эти шаги в новом блоке интеграции.
У каждой группы собственный webhook URL, secret key, токен и диагностика.

## Что происходит при новом сообщении

1. VK отправляет событие `message_new` в ArtistCRM.
2. PartyCRM находит компанию и конкретную VK-интеграцию по webhook token.
3. PartyCRM проверяет `secret` и `group_id` выбранной группы.
4. Первое сообщение из нового `peer_id` создает заявку со статусом `draft`.
5. Источник заявки берется из `Название интеграции`.
6. Переписка сохраняется в `PartyVkConversations` вместе с `vkGroupId` и
   `vkIntegrationName`.
7. Все сообщения сохраняются в `PartyVkMessages`.
8. Повторные сообщения из того же `peer_id` не создают дубликаты заявок.

## Переписка

В карточке VK-заявки и карточке клиента доступен блок `Переписка VK`.

Из CRM можно:

- видеть историю входящих сообщений;
- отправлять ответ в VK;
- сохранять статус отправки сообщения;
- вручную привязывать conversation к клиенту или заявке через защищенный API.
- вручную создать или привязать VK-диалог к клиенту по VK ID, короткому имени
  или ссылке в модалке `Объединение контактов`.

Ручная привязка по VK ID создает связь в `VkConversations` и обновляет контакт
клиента `Clients.vk`. Отправка ответа возможна только если VK разрешает группе
писать этому пользователю. Для исходящего ответа PartyCRM выбирает токен VK по
`vkGroupId` диалога.

## Безопасность

- Токены сообществ хранятся в настройках компании.
- Webhook URL содержит token конкретной VK-интеграции.
- Callback API `secret` проверяется на каждом входящем событии.
- Все выборки и записи ограничены `tenantId`.
- В логах не должны появляться токены VK и полные payload с персональными
  данными без необходимости.
