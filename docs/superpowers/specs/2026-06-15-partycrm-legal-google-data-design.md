## Документы PartyCRM

Страницы сохраняют текущую визуальную структуру PartyCRM и публичную индексацию. Все упоминания `ArtistCRM`, `artistcrm.com` и `artistcrm.ru` заменяются на PartyCRM и `https://partycrm.ru`.

Политика конфиденциальности описывает:

- данные аккаунта и данные, вносимые компанией в CRM;
- OAuth-данные Google и идентификаторы событий календаря;
- одностороннюю передачу данных заказа из PartyCRM в выбранный Google Calendar;
- отсутствие продажи Google user data и использования для рекламы;
- хранение OAuth-токенов только для работы подключенной интеграции;
- отключение интеграции в настройках компании и отзыв доступа в Google Account;
- запрос удаления аккаунта и связанных данных по электронной почте;
- ссылку на Google API Services User Data Policy и соблюдение Limited Use requirements.

Пользовательское соглашение использует терминологию PartyCRM: компании, клиенты, заказы, точки, сотрудники и интеграции. Оно ссылается на актуальные PartyCRM privacy/consent страницы.

Согласие на обработку персональных данных сверяется с теми же реквизитами, доменом и датой действия.

## Регистрация

Клиент отправляет три булевых поля:

- `consentTerms`;
- `consentPrivacyPolicy`;
- `consentPersonalData`.

Кнопка регистрации недоступна во время запроса, а сервер является окончательным контролем. При отсутствии любого подтверждения API возвращает `400` с единообразным сообщением без создания пользователя.

Из `partyUsersSchema` и payload создания пользователя удаляются:

- `consentPrivacyPolicyAccepted`;
- `consentPersonalDataAccepted`;
- `privacyPolicyAcceptedAt`.

Новая миграция не нужна: старые поля в существующих MongoDB-документах не влияют на приложение, а Mongoose-схема перестает их использовать.

## Проверка

- Тест API регистрации подтверждает отказ при отсутствии каждой из трех галочек и отсутствие consent-полей в создаваемом пользователе.
- Статическая проверка документов исключает остаточные ссылки ArtistCRM в PartyCRM и подтверждает Google Calendar/Limited Use текст.
- Проверяется footer главной страницы и три ссылки регистрации.
- Запускаются точечный ESLint и production build PartyCRM.
- Для ArtistCRM запускается ESLint измененного файла или доступная сборочная проверка без изменения его runtime-кода.
