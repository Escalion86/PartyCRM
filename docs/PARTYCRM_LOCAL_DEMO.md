- «День рождения Маши — показ аванса»: стоимость 15 000 руб., без оплат, для живого показа.
- «День рождения Артёма — аванс внесён»: поступило 5 000 руб., остаток 10 000 руб.
- Календарь: мероприятия 2–6 ноября 2026 года, часовой пояс Asia/Krasnoyarsk.
- Задачи: новые, в работе, выполненная, просроченная и самостоятельная задача без заказа.
- «Праздник завершён — отчёт и расчёт»: отправленный отчёт для проверки управляющим.
- «Проверка транзакций — аванс 5 000 ₽»: отдельный заказ, созданный для проверки записи после настройки MongoDB.

## Ограниченные должности

Добавлены два отдельных аккаунта и пользовательские должности с явной матрицей прав:

- **Менеджер по звонкам**: клиенты внутри рабочего редактора заказа, создание и редактирование заявок, бриф, стоимость, календарь и задачи перезвона. Назначения исполнителей, гонорары, платежи, расходы, маржа и управление компанией закрыты. По согласованию журнал телефонии не включён.
- **Художественный руководитель**: просмотр заказов и расписания, назначение команды, гонорары, фактические выплаты исполнителям и задачи подготовки. Клиентская стоимость, поступления, прочие расходы, маржа и управление компанией закрыты. Справочник сотрудников не предоставлен для изменения.

Оба работают через `/performer/work`; учётные данные находятся в локальном
`output/demo/limited-accounts.md`. Каждому добавлена демонстрационная задача.
Через API проверены вход, выдача заказов без скрытых полей, задачи,
разрешённое изменение стоимости менеджером и назначение/выплата худруком,
отказ запрещённых финансовых операций и изменений настроек.
Прямой переход в настройки компании перенаправляет из закрытого раздела.
Проверочная выплата 3 000 руб. относится к отдельному заказу проверки транзакций,
основной заказ для демонстрации аванса не изменён.

## MongoDB на этом ПК

Служба MongoDB переведена из standalone в одноузловой replica set `localrs`.
Участник: `localhost:27017`; сетевой доступ по-прежнему ограничен `127.0.0.1`.
База PartyCRM: `partycrm`. Строка подключения приложения не изменялась.
Одноузловой replica set обеспечивает транзакции, но не резервирование на другом сервере.

Конфигурация: `C:\Program Files\MongoDB\Server\8.2\bin\mongod.cfg`.
Копия прежней конфигурации: `C:\Program Files\MongoDB\Server\8.2\bin\mongod.cfg.before-party-demo-20261103-132531.bak`.
Это копия конфигурации, не резервная копия баз данных.

Через API локального приложения проверены создание задачи, запись аванса 5 000 руб.
и повтор запроса с тем же ключом без дублирования платежа. Проверочные записи
относятся только к демонстрационной компании. Основной заказ для показа сохранён без оплат.
